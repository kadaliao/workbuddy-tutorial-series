# 第 14 集：安装设计师技能，让 AI 做动效视频

## 交付目标

由 WorkBuddy 实际调用 Emil Kowalski 的设计与动效技能，制作可直接播放的 MP4 动效样片。Codex 负责实机操作、录屏、中文配音、教程剪辑和验收。

本期使用全新任务「安装设计师技能并制作动效样片视频」，工作空间为 `/Users/Shared/WorkBuddy-动效视频`。教程仅采用这个任务及其成品的录制素材。

## 实际提示词

> 先给 WorkBuddy 安装这位设计师的全部 skills：https://github.com/emilkowalski/skills 。保留原有技能；若已经安装，请核验可读取并直接使用。
>
> 然后使用 emil-design-eng、animate 等技能，制作一个动效样片，给我展示各种各样的动效风格。内容越丰富越好。要体现极好的审美和动效能力。
>
> 最终交付是一条可以直接播放的 MP4 视频：60～90 秒，1920×1080，30fps。以全屏 motion reel 的形式编排至少 12 组明显不同的动效语言，有精致的开场、章节节奏、流畅转场和结尾。字体、构图、色彩和运动都要有统一的艺术指导，中文标题简洁克制，画面丰富。请自由发挥设计与动效能力。
>
> 请实际渲染编码出 MP4，配上与节奏匹配的本地程序合成原创配乐，并提供封面、可修改的渲染源码和启动命令。可以用本机现有的 ffmpeg、浏览器或其他合适的渲染工具。完成前使用 review-animations 审查并修复，再检查视频解码、时长、尺寸、帧率和首中尾关键帧。所有成品保存在当前工作空间，直接完成制作，不要公开发布。

## 制作规范

- 技能在此任务开始时已安装；实录展示重新核验与实际调用，不表述为首次安装。
- 录屏源从 `05-clean-video-task.mov` 开始；执行等待可删减、加速并明确标注。
- 样片本体保留原速和自身配乐。
- 教程为 1080p、30fps，中文旁白与独立字幕条，沿用系列片头与既有授权配乐。
- 制作阶段仅交付本机文件；本次仓库整理将成片与工程包归档到 GitHub Release。视频号、YouTube、bilibili 的发布状态另行记录。

## 正式版本与复现入口

本集采用独立视频任务的正式成片；早期交互动效展厅方案不再作为仓库入口，相关文件保留在本机备份。

- 编排与完整口播：`build/ep14.py`。
- 最终拼接：`build/assemble_ep14.py`。
- 口播文本与听验记录：`audio/ep14/`。
- 封面：`publish/covers/ep14-3x4.png`、`ep14-4x3.png`；样片封面为 `ep14-motion-reel.png`。
- 媒体与可编辑工程：[第14集 Release](https://github.com/kadaliao/workbuddy-tutorial-series/releases/tag/v1.1)。

先下载 Release 的 `ep14-editing-project.zip` 与 `ep14-motion-reel.mp4`。工程包含配音、逐字时间、短素材和片头，素材缓存沿用 `build/ep14clean/` 名称；它是缓存目录，不是第二个正式版本。按压缩包 README 安装依赖并将媒体解压到仓库对应目录后，可运行：

```sh
build/venv/bin/python build/ep14.py A开场 B技能 C需求 D制作 E样片
build/venv/bin/python build/ep14.py F验收 G收尾
build/venv/bin/python build/assemble_ep14.py /绝对路径/ep14-motion-reel.mp4
```

输出 `ep14-v1.mp4`，约 3 分 31 秒。98.711 秒开始完整样片，170.711 秒进入验收与复用。重新制作需要本机制作环境；本次整理没有重新生成配音或重新渲染成片。

## 口播稿（成片实际使用版）

【A开场】
给 WorkBuddy 装上设计师的技能，再让它直接做一条动效视频，效果怎么样？这一期，我们从技能准备、下达需求，一直做到真正导出和播放视频。

【B技能】
先选一个独立的工作空间，把设计师的仓库地址交给 WorkBuddy。要求安装全部技能，保留原有内容；如果已经装过，就核验后直接使用。这台机器检测到了十五个技能，和仓库内容一致。随后，它实际加载了设计规范与动效制作技能，并读取审查标准。

【C需求】
需求先说清楚：制作一个动效样片，展示各种各样的动效风格，内容丰富，审美和动效能力都要好。接着把交付写具体：六十到九十秒，横屏一零八零，三十帧，最终输出能直接播放的 MP4。再要求完整编排、配乐、封面和源码，完成前审查并检查视频。

【D制作】
提交后，WorkBuddy 先检查浏览器、字体和编码工具，再做一张中文测试帧。确认画面能正常渲染后，才继续制作样片。这段执行需要等待，教程里做了删减。你自己操作时，可以重点看任务列表和实际输出文件。

【E样片】
接下来，完整看一遍 WorkBuddy 做出的动效样片。这里保留原速和它生成的配乐。

【F验收】
最后，打开导出的 MP4，检查开场、各个章节和结尾，再确认分辨率、帧率与声音。这次成品是七十二秒，横屏一零八零、三十帧，带有独立配乐。封面、源码和启动脚本也都放在同一工作空间。以后要换配色、节奏或者文案，可以从这些源码继续改。

【G收尾】
这一期的流程可以直接复用：给出技能仓库，检查安装结果，新开任务明确调用，最后验收真实作品。想让 AI 做出好动效，别只说要高级。把想看的风格、怎么体验、怎样算完成，一起说清楚。
