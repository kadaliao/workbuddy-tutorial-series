# 第 11 集：连接器——邮箱、文档、会议一键连

时长目标：5～6 分钟｜**需要用户本人授权一个连接器**

## 一句话结论
连接器让它能读写你的邮箱、文档、会议；授权只给需要的那一个，读为主、写先出草稿，发送前你自己看。

## 事实依据
- 实测 shots/38：连接器页有通达信、腾讯自选股、QQ邮箱、ima、乐享知识库、腾讯文档、腾讯会议、企业微信、飞书、钉钉、腾讯问卷等，右上「自定义连接器」。
- 官方：添加 = 连接器页卡片右上「+」授权；使用 = 连接器页「去对话」，或输入框「+ > 连接器」开启，或任务中按引导卡片连接。QQ 邮箱连接器需扫码（QQ 邮箱 App 7.1.5 及以上）。

## 镜头与操作
| 镜头 | 操作 | 状态 |

| A 开场 | 对话里它读取了一份腾讯文档（或邮箱草稿）并给出摘要 | 依赖 D |
| B 连接器页 | 专家·技能·连接器 → 连接器；滚动卡片；悬停「+」与「自定义连接器」 | 可由我录 |

| D 授权一个 | 建议腾讯文档（只建一个虚构的测试文档）；点「+」，按提示授权 | **需用户本人扫码/授权** |

| G 断开 | 连接器卡片上断开/移除授权的位置 | 授权后我录 |

## 口播稿（成片实际使用版）

【A开场】
它不只能读你电脑里的文件。接上连接器，你的在线文档、邮箱、会议，它也能用。今天讲连接器。

【B页面】
左边，专家、技能、连接器，选连接器。这里列着能接的服务：腾讯文档、QQ 邮箱、腾讯会议、企业微信、飞书、钉钉，还有更多。右上角还能自定义。

【C输入框】
在对话里也能开：点加号，连接器，这次要用哪个，就点哪个后面的连接。

【D授权】
第一次用，要先授权。点卡片右上角的加号，它会先告诉你要拿什么权限：读取文档内容，编辑和管理文件。看清楚再点前往授权，然后扫码同意。我的建议：只授权你这次真要用的那一个，别一口气全连上。

【E写】
写入要更小心。我让它在腾讯文档里新建一个测试文档，写一段虚构的会议纪要，还特意说了：先把草稿发给我看，确认后再创建，只操作这一个文档。它先把草稿列出来，等我回复确认，才真的去创建，最后告诉我只建了这一个文档。邮件也一样，先出草稿，你看过再发，发出去就收不回来。

【F读】
读就简单了。新开一个任务，让它读这份文档，三句话总结。不到一分钟，决议、负责人、下次开会时间都出来了，还说明了只读了这一个文档，没做修改。

【G断开】
已连接的卡片上有个绿点。不用了，点开卡片，这里有解绑。

【H收尾】
今天三句话：要用哪个连哪个，写入先出草稿，用完记得解绑。下一集，个性化、记忆和模型，越用越顺手。
